# Listener

**Listener** is an Android application specifically designed and optimized for **E-ink displays**. It allows you to listen to YouTube audio tracks and Podcasts in a clean, strictly black-and-white interface with zero animations or grayscale elements.

## 🚀 Key Features

- **E-ink Optimized UI**: High-contrast B&W interface with no animations to prevent ghosting.
- **YouTube & LBRY Audio**: Search and listen to YouTube videos and LBRY/Odysee content as audio tracks.
- **Podcast Support**: Support for RSS-based podcast feeds.
- **Subscriptions**: Subscribe to your favorite YouTube channels, LBRY creators, and Podcasts.
- **Offline Downloads**: Download tracks for offline listening using Android's native Download Manager.
- **Smart Playback**: Remembers your playback position for each track individually.
- **Adjustable Speed**: Change playback speed from 0.5x up to 2.0x.
- **Background Playback**: Full Media3 integration for reliable background play and lock screen controls.
- **Data Saving**: Option to restrict downloads and updates to Wi-Fi only.

## 🛠 Tech Stack

- **Kotlin** & **Jetpack Compose**
- **Media3 (ExoPlayer)** for audio playback
- **NewPipeExtractor** for YouTube integration
- **WorkManager** for background subscription updates
- **Material 3** (Customized for B&W)
